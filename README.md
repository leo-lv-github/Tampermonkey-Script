# Tampermonkey-Script

油猴（Tampermonkey）实用脚本集合。

---

## 🔄 如何自动获取最新代码（脚本自动更新）

为了确保使用的脚本始终保持最新版，建议按照以下方法配置自动更新或关联更新源：

### 方法一：开启油猴的“自动更新”设置（最常用）

如果脚本最初是通过 GitHub 链接安装的（或者代码头部含有 `@downloadURL` / `@updateURL`）：

1. 点击浏览器右上角的油猴图标，选择 **“管理面板” (Dashboard)**。
2. 点击右上角的 **“设置” (Settings)** 选项卡。
3. 将 **“配置模式”** 切换为 **“高级” (Advanced)**。
4. 找到 **“脚本更新” (Script Update)** 模块：
   - **检查更新间隔 (Check interval)**：设置为 `每小时`、`每天` 或 `每次浏览器启动时`。
   - **更新脚本 (Update scripts)**：确保已勾选开启。
5. 保存后，油猴会在后台定期对比 GitHub 上的版本号，检测到新版本后会自动下载覆盖。

### 方法二：通过 GitHub Raw 链接重新安装一次（关联更新源）

如果你的脚本最初是手动复制粘贴到油猴里的，油猴无法识别它的 GitHub 来源，因此不会自动更新。

**解决方法：**

1. 打开 GitHub 仓库中该脚本的页面（如 `xxxx.user.js`）。
2. 点击页面右上角的 **`Raw`** 按钮（或直接打开 `https://raw.githubusercontent.com/.../xxxx.user.js` 链接）。
3. 油猴会自动拦截并弹出脚本安装界面。
4. 点击 **“更新”** 或 **“重新安装”**。

> **效果**：完成这一步后，油猴会自动把该 Raw 链接记录为更新源，后续即可按照【方法一】自动获取最新代码。

---

### 💡 补充说明
- **手动检查更新**：在油猴“管理面板” -> “已安装脚本”列表中，点击目标脚本的“最后更新”时间列即可立即检查更新。
- **版本号机制**：油猴检测更新依赖于脚本头部的 `@version` 字段，只有 GitHub 上的版本号高于本地时才会自动更新。
